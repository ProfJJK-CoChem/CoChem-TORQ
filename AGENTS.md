# Working on CoChem-TORQ

Start with [the agent handoff](docs/development/AGENT_HANDOFF.md), then read the
normative SRS, method-matrix implementation contract and complete requirement
audit linked there. The handoff records verified evidence, unfinished work and
the latest access observations. It does not qualify the full scientific product.

The continuing objective is to complete the SRS implementation and independently
validate each advertised scientific profile. Preserve all accepted D01–D12 and
ARCH-01–ARCH-12 decisions. Do not substitute another electronic method for exact
revDSD or weaken an applicability test to obtain a spectrum.

Student deployment and its private Codespaces/Actions pilot are on hold until
the user lifts that hold. Ordinary public source CI, local implementation,
reference acquisition and authorized research calculations can continue.
GitHub Actions is the canonical calculation environment; Codespaces is the
canonical interface. BASE, TOPOS and TORQ must retain explicit versioned handoffs.

Use genuine engines and authentic source data. Missing scientific quantities
stay unavailable. Never fabricate frequencies, energies, gradients, spectra,
uncertainty, reference records, execution receipts or human attestations.
Mathematical/process checks and real-engine qualification are separate evidence
lanes. Keep failed, skipped, blocked and unrun outcomes distinct.

Preserve user changes and original scientific evidence. Verify actual Git/source
identity before attaching test results to code. Keep shared credentials, their
private asset configuration and licensed archives out of this public repository.
Use inherited authentication, network proxy and TLS trust; never bypass an
access denial or extract credentials. Recheck actual requests before carrying
forward an old network/authentication blocker.

An existing cloud task is already isolated: use its current checkouts; do not
create another worktree unless requested. Inspect resources before native runs.
Do not delete original results or protected environments to make room for tests.
Run checks appropriate to the changed scope, inspect genuine results, and update
the audit without converting source presence or software passes into scientific
qualification.

The implementation supplies an experimental, bounded CPU route for supplied candidate structures: explicit restricted electronic structure, optimized-coordinate checks, isotope-specific equilibrium moments/constants, harmonic characterization and finite-J rigid-rotor screening using actual dipoles. They do not establish exact revDSD, general vibration-corrected B0 or laboratory/astronomical identification accuracy.

Hosted integrity evidence from an earlier source snapshot does not qualify the final source. The default-branch calculation endpoint, live Codespaces workflow, original-byte artifact download and deployed operational lifecycle still require actual evidence.

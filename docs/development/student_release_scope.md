# Student release scope and remaining full-SRS qualification gates

Reviewed 2026-10-08 against the current implementation SRS. This document is a coverage view of the [machine-readable full-SRS audit](full_srs_requirement_audit.json), not a scientific certification or deployment report. Source and test links identify implementation or relevant checks; they are not passing execution evidence. The final frozen-source receipts and canonical deployed student journey remain separate gates.

The implementation supplies an experimental, bounded CPU route for supplied candidate structures: explicit restricted electronic structure, optimized-coordinate checks, isotope-specific equilibrium moments/constants, harmonic characterization and finite-J rigid-rotor screening using actual dipoles. It retains valid earlier results when later stages fail or are unavailable. Local PBE-D4/B3LYP-D4/MP2 derivative and anharmonic validation profiles are separately named controlled-validation routes. They do not establish exact revDSD, general vibration-corrected B0 or laboratory/astronomical identification accuracy.

GitHub Actions is the canonical calculation environment; GitHub Codespaces is the canonical interface. CoChem-BASE and CoChem-TOPOS are independent, version-pinned producer/consumer environments. Hosted integrity evidence from an earlier source snapshot does not qualify the final source. The default-branch calculation endpoint, live Codespaces workflow, original-byte artifact download and deployed operational lifecycle still require actual evidence. See [canonical environments](canonical_environments.md) and [release candidate readiness](release_candidate_readiness.md).

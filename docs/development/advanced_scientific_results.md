# Advanced scientific payload contracts

`cochem_torq.spectroscopy.results` supplies strict payload schemas for the existing experimental force-field, resonance, vibrational-only VPT2 and rigid-rotor calculations. `StageResult` validates their available values using `ADVANCED_VALUE_SCHEMAS`; unavailable stages still carry no substitute value. These schemas verify structural and numerical consistency. Scientific qualification and verification of native artifact bytes remain separate requirements.

The registered observables are `anharmonic_force_field`, `resonance_analysis`, `vibrational_only_vpt2` and `rigid_rotor_transitions`. Existing numerical payload fields remain present. Each value adds a required `scientific_context` versioned as `cochem.torq.scientific-context/1`, binding actual atom order/identifiers, resolved isotope numbers/masses/source policy, ordered geometry, coordinate frame, mode order/basis, recipe, protocol and upstream artifact hashes. Geometry and frame digests use the application's RFC 8785 canonical serialization. When no source atom identifiers exist, `input_ordinal` records explicitly generated identifiers as metadata; this does not infer topology or change atoms.

`make_scientific_context` requires the actual molecule record, resulting geometry, retained `isotope_record` observations, recipe/protocol digests, a nonempty distinct list of actual parent artifact digests and an explicit evidence class. Supply the actual `HarmonicResult` for mode-based quantities and actual principal-axis columns for the rotational catalog. The helper checks harmonic geometry/masses, declared axis orientation and requested isotope identity. It never rounds average atomic masses into isotope numbers. The most-abundant-isotope default remains visible as its recorded selection policy; natural isotope ensembles require a different model.

Force fields require complete permutation-symmetric cubic/quartic tensors on the stated mode basis, both displacement scales, every distinct displacement record and the actual zero-displacement reference energy. Convergence flags must agree with the retained fine/coarse tensors and tolerances. Source and displacement-manifest digests are recomputed from the actual payload. Engine evidence requires a native result-manifest digest for every displacement; mathematical model calculations are separately labeled. The direct force-field builder also checks frequency/eigenvalue units, orthonormal modes, isotope mass weighting and dimensionless-coordinate normalization before running any energy calculation.

Vibrational-only VPT2 retains ground-plus-fundamental state corrections and checks that the reported ground energy and fundamentals follow those corrections. Its `rotation_vibration_available` and `independent_scientific_qualification` remain false. Resonance occupations must span the full mode basis and identify distinct coupled states. This contract does not supply Coriolis interactions or certify a resonance model from a threshold alone.

Rigid-rotor catalogs require the declared principal frame, dipole origin, thermal/intensity conventions and bounded distinct transition quantum numbers. Their `identification_qualified` flag remains false. Dimensionally consistent rigid-rotor screening lines cannot stand in for vibration-corrected constants, centrifugal-distortion terms, nuclear-spin symmetry treatment or calibrated identification accuracy.

The genuine anharmonic runner saves typed `force-field.json`, `resonance-analysis.json` and, when available, `vibrational-vpt2.json` files. Force-field parents are actual protocol/harmonic-input file hashes and displaced native manifests; later stages link actual upstream result-file hashes. Raw failed calculations remain retained. The final research artifact manifest covers these files.

The contract tests use actual isotope-library records and explicitly mathematical spring, polynomial and rotor calculations. The separately executed anharmonic tests validate real RHF/STO-3G displaced calculations and parent bytes. Neither evidence lane opens the exact revDSD, rotational VPT2 or identification release gates.

Mass-dependent scientific cache identities retain ordered isotope mass numbers, masses, tabulated uncertainties, selection policies and the source database checksum/version. Local database paths are excluded. A sealed bundle persists these actual mass inputs even when its calculation failed; isotope data resolution is separate from engine success. Verification uses the retained evidence and compares it to result isotope records when present, without substituting the viewer's installed mass database. The key records reproducible inputs and does not establish accuracy or activate reuse of an unqualified result. Genuine rejection-record portability tests verify bundles in a fresh interpreter without importing the isotope database provider.

The bundle verifier also binds advanced contexts to the retained isotope, harmonic mode-basis and principal-inertia payloads. Schema-valid but inconsistent metadata in a resealed genuine calculation is rejected. This establishes internal consistency of retained bytes, not signatures or independent physical validation. Strong one-mode anharmonic coupling diagnostics remain distinct from accidental Fermi/Darling–Dennison resonance candidates; crossing the configured perturbative applicability threshold retains the actual force field and blocks VPT2 without claiming that a perturbative polyad alone resolves its validity.

## Classification rule

**Agent-feasible now** includes source inspection, public web/article/API acquisition when authorized, reference extraction and provenance, software implementation, equation derivation, independent algorithm/code comparison, local mathematical/process checks and bounded real-engine campaigns within provided compute. **Agent-feasible with resources** includes expensive force fields, multi-system calibration, GPU/cluster runs or proprietary native comparisons once legitimate access and sufficient authorized compute exist. Scientific difficulty, a long runtime or an unfamiliar literature method does not turn research implementation into a human-only task. No time/cost completion estimate is implied: some algorithms require iterative research and may fail applicability/accuracy checks.

An `independent_reference` gate can often use published experimental data, a separately derived solver or a genuinely independent implementation acquired and exercised by agents. Independent means independent evidence/assumptions appropriate to the gate, not automatically a human reviewer. An agent's review must be labeled as agent review; it cannot be represented as a named person's review, an external lab's approval or an authenticated independent scientific signoff.

Human prerequisites below are conditional and narrow. They block the particular exercise or authority they name, not all coding under a requirement. Even while a prerequisite is outstanding, agents can implement open routes, retrieve available sources, prepare manifests, propose scope/targets, reproduce existing data and preserve honest unsupported states.

The present source/comparison work does **not** complete all agent-executable work. Exact revDSD response and higher derivatives, general resonant GVPT2 and the bounded independent accuracy campaign remain substantive agent-owned implementation/research, alongside the other workstreams below. Restoring denied source access does not explain or block every local algorithm, contract or process task. Do not reassign those unfinished tasks to the researcher merely because reference curation or a platform action is pending.

## Reference retrieval is agent work

NIST/catalogue/article/SI acquisition, DOI/source reconciliation, equations, permitted full texts, structured-table extraction and source-byte hashing are normal agent tasks. Retain retrieval provenance, version/date, citation, units, isotopologue, state and Hamiltonian conventions; preserve failures and unclear permissions. Extracting a published table does not by itself prove independence, reuse rights, target relevance or a calibrated uncertainty model. A catalogue prediction is not an experimental reference merely because it is public.

**QCSchema is an interchange format; QCArchive is a dataset service.** Schema validation does not supply reference data. Agents can query QCArchive metadata and actual authorized records through its API, then assess molecule/state/method/basis/driver/convergence/provenance and split independence. An electronic energy dataset cannot alone calibrate experimental B0, line frequencies or intensities. Public API access, accessible literature or already published experimental observations are not inherently human-only dependencies. If an API contains no relevant records, record that negative finding and choose another authentic source rather than inventing a fixture.

The [published-reference product](published_reference_product.md) records the actual acquired sources and comparisons. The bundled QM9 members and working descriptive runner are available now; extending them to accepted, method-matched and independently reviewed references remains agent work. A single-case comparison does not pass a multi-family blind benchmark or the complete scientific release.
